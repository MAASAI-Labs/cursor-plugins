# Space Launch & Starlink Tracker

Upcoming launches worldwide with live countdowns (Launch Library 2), Starship flight status and news, and visible ISS, Tiangong, Hubble and Starlink-train passes for any location using CelesTrak orbital data. Every answer cites its source and fetch time.

- Hosted MCP server: `https://space-launch-tracker-mcp.vercel.app/mcp` (Streamable HTTP)
- Source code: https://github.com/MAASAI-Labs/space-launch-tracker-mcp
- Free to use. MIT licensed.

## Use in Cursor

1. Install **Space Launch & Starlink Tracker** from the Cursor Marketplace (publisher: MAASAI Labs).
2. Open Cursor Settings, then MCP, and check that the `space-launch-tracker` server is enabled.
3. Ask the agent a question that needs it. See the source README for example prompts.
