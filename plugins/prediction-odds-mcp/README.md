# Prediction Market Odds

Live odds from Polymarket and Kalshi in one place: search markets by topic, trending markets by 24h volume, live top-of-book for any market, cross-venue comparisons that only match markets with identical resolution terms, and short briefings on the biggest moves. Read-only, sourced and timestamped; probabilities, not advice.

- Hosted MCP server: `https://prediction-odds-mcp.vercel.app/mcp` (Streamable HTTP)
- Source code: https://github.com/MAASAI-Labs/prediction-odds-mcp
- Free to use. MIT licensed.

## Use in Cursor

1. Install **Prediction Market Odds** from the Cursor Marketplace (publisher: MAASAI Labs).
2. Open Cursor Settings, then MCP, and check that the `prediction-odds` server is enabled.
3. Ask the agent a question that needs it. See the source README for example prompts.
