# Domain Hunter

Brainstorm brandable domain names from a product idea and check live availability through registry RDAP (WHOIS fallback) with Porkbun list prices. Also does registration lookups with expiry/drop signals, DNS records with an SPF/DMARC check, live TLS certificate details and TLD pricing. It never buys anything; purchase links are returned only on request.

- Hosted MCP server: `https://domain-hunter-mcp.vercel.app/mcp` (Streamable HTTP)
- Source code: https://github.com/MAASAI-Labs/domain-hunter-mcp
- Free to use. MIT licensed.

## Use in Cursor

1. Install **Domain Hunter** from the Cursor Marketplace (publisher: MAASAI Labs).
2. Open Cursor Settings, then MCP, and check that the `domain-hunter` server is enabled.
3. Ask the agent a question that needs it. See the source README for example prompts.
