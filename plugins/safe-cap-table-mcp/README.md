# SAFE & Cap Table Calculator

Model any startup round in seconds: post- and pre-money SAFEs (cap, discount, MFN), convertible notes, priced rounds, multi-tranche and extension rounds at different caps, option pool top-ups (pre vs post-money) and advisor/placement fees. Returns before/after cap tables, per-holder dilution and fully diluted ownership, validated against YC's standard SAFE examples. Works for any market.

- Hosted MCP server: `https://safe-cap-table-mcp.vercel.app/mcp` (Streamable HTTP)
- Source code: https://github.com/MAASAI-Labs/safe-cap-table-mcp
- Free to use. MIT licensed.

## Use in Cursor

1. Install **SAFE & Cap Table Calculator** from the Cursor Marketplace (publisher: MAASAI Labs).
2. Open Cursor Settings, then MCP, and check that the `safe-cap-table` server is enabled.
3. Ask the agent a question that needs it. See the source README for example prompts.
