# Orbital Watch

Live satellite and debris tracking from CelesTrak, predicted close approaches (CelesTrak SOCRATES), and NOAA SWPC space weather (flares, Kp, geomagnetic storms, alerts) with plain-English impact on GPS, HF radio and Starlink. Informational only, sourced and timestamped.

- Hosted MCP server: `https://orbital-watch-mcp.vercel.app/mcp` (Streamable HTTP)
- Source code: https://github.com/MAASAI-Labs/orbital-watch-mcp
- Free to use. MIT licensed.

## Use in Cursor

1. Install **Orbital Watch** from the Cursor Marketplace (publisher: MAASAI Labs).
2. Open Cursor Settings, then MCP, and check that the `orbital-watch` server is enabled.
3. Ask the agent a question that needs it. See the source README for example prompts.
