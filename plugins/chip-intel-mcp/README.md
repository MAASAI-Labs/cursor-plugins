# Chip Intel

Source-cited AI accelerator specs and side-by-side comparisons (NVIDIA, AMD, Google TPU, AWS Trainium), a TSMC/Samsung/Intel process-node map, US export-control screening against the official Consolidated Screening List (incl. BIS Entity List), SEC filings and revenue for major chip companies, and chip news briefings. Every figure links to its source.

- Hosted MCP server: `https://chip-intel-mcp.vercel.app/mcp` (Streamable HTTP)
- Source code: https://github.com/MAASAI-Labs/chip-intel-mcp
- Free to use. MIT licensed.

## Use in Cursor

1. Install **Chip Intel** from the Cursor Marketplace (publisher: MAASAI Labs).
2. Open Cursor Settings, then MCP, and check that the `chip-intel` server is enabled.
3. Ask the agent a question that needs it. See the source README for example prompts.
